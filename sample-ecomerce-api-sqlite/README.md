# E-Commerce Mock API Server (Node.js + Express + SQLite)

Kho lưu trữ mã nguồn Backend API Server mẫu phục vụ cho bài tập Capstone E-Commerce CRUD.

## 🚀 Hướng dẫn khởi chạy

```bash
# 1. Clone repository về máy cá nhân (Link do Mentor cung cấp)
git clone <URL_REPOSITORY>
cd <TEN_THU_MUC_VUA_CLONE>

# 2. Cài đặt các packages cần thiết (chỉ cần chạy lần đầu)
npm install

# 3. Khởi động server
npm start
```

Server sẽ chạy tại: `http://localhost:3000`

- Chế độ phát triển (tự reload khi sửa code): `npm run dev`
- Reset lại toàn bộ database mẫu ban đầu: `npm run seed`
- Xem tài liệu API đầy đủ tại: [API_DOCUMENTATION.md](./API_DOCUMENTATION.md)
- File test nhanh API bằng extension VSCode REST Client: [requests.http](./requests.http)
